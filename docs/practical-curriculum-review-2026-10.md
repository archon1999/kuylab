# Independent exercise and theory review — 25 October 2026

The review covers every independent exercise and practical theory lesson. These
remain separate from the seven composition courses. It does not change any source
composition MIDI, composition lesson range or stage identity.

The catalog now has **16 exercise families × 3 levels = 48 exercises**, **24 theory
lessons**, **25 optional activities**, and **five pairs of listening comparisons**.
All teaching copy is authored in Uzbek, Russian and English. Each lesson has a
concept, an exact MIDI description, counting/listening detail, a practical method,
a common pitfall and a self-check. Self-checks do not grade playing or gate access.

Every optional theory activity also displays a concept primer **before** the
question, with a link back to the full explanation. The interval primer explicitly
defines third/major third/minor third and counts C→C♯→D→D♯→E as four adjacent-key
steps, without counting the starting note as a step. It explains C4 and distinguishes
the fourth/fifth used in the listening question. Explanations are available before
an answer is checked, rather than hidden solely in success feedback.

## Musical corrections

- Contrary C major now sends RH C4→C6 and LH C3→C1 on actual C-major degrees,
  returning to their starting tonics. Mirroring semitone offsets previously gave
  the LH altered notes and placed it above RH. Parallel and contrary fingerings
  are now explained separately. Scale attacks are eighths, with explicit final
  tonic holds instead of a nonstandard division of a sixteen-quarter block.
- Arpeggios explicitly return to C in every cycle. The three patterns are
  C–E–G–E–C, C–E–G–C–G–E–C and the two-octave extension. End holds and full
  four/eight-quarter windows are retained; ascending and descending fingerings
  match those patterns.
- Easy chord resets now keep C in both hands. Its old changing bass contradicted
  the explanation of a single C-major chord. Advanced chords are explicitly
  Cmaj7–Fmaj7–G7–Cmaj7, with exact notes given in the lesson.
- The 3:2 example now continues on half-quarter RH and three-quarter LH spacing
  through twelve-quarter blocks. The old sixteen-quarter boundary restarted the
  LH before its shared cycle finished. The explanation distinguishes the six
  subdivisions of one shared 1.5-quarter cycle from the quarter-note tempo.
- Pedal clears at the next chord attack, then re-engages just afterward. It no
  longer releases 0.15 quarters before that attack while claiming delayed pedal.
  Advanced mid-chord clearing is explicit: re-pedaling does not resurrect a bass
  whose key has already released. Final pedal release is encoded. Only these
  pedal examples contain CC64; no pedal is invented for other studies.
- Advanced continuity now keeps the LH pulse when RH rests on beat 4. Copy
  explicitly identifies which hand rests. Authored phrase windows retain their
  intended ending silence rather than ending immediately on the last note-off.
- Uzbek “major/minor” wording now says **one semitone**, avoiding the ambiguous
  “bir yarim ton.” Meter comparison labels identify the **first beat** of each
  group. Rhythm lessons distinguish notated rhythmic value, key hold and decay.

## Exercise review, all three levels

Pitch register uses C4 for middle C. Tempos 66/80/96 are quarter-note BPM for the
authored files, not readiness requirements. The learner can adjust playback.

## Theory review, topic by topic

| Topic | Concrete example and teaching repair/addition |
|---|---|
| Keyboard and semitone | C4–G4 chromatic path; two/three-black-key landmarks, E–F/B–C and enharmonic spelling |
| Pulse and rhythm | Sixteen equal LH quarters against changing RH entries; count pulse independently of note count |
| Durations | Four-quarter groups using 4, 2, 1 and 0.5 values; distinguish rhythmic spacing, slightly detached key holds and acoustic tails |
| Rests | Four groups with attacks on 1–2 or 1–3; count missing beats and prepare a quiet re-entry |
| Intervals | C4 to D/E/F/G/A/B/C5; interval number counts letters, quality counts semitones |
| Major/minor | C–E–G versus C–E♭–G; exactly one semitone changes, rather than an emotional label |
| Triads | C/E/G separately then together; root/third/fifth and simultaneous attacks |
| Inversions | CEG, EGC, GCE; distinguish root from lowest note, not a new E/G chord |
| Tonic/dominant | C–G/B–C; trace C–B–C and explain I/V relative to C major |
| Arpeggio | Block CEG then CEGC/GEC; recognize chord-tone set rather than scale neighbors |
| Simple meter | Twelve quarter attacks in four 3/4 bars; beat-one accents, meter versus triplet versus tempo |
| Syncopation | RH offbeat holds across short LH quarters; identify entry and sustain independently |
| Legato/staccato | Near-full versus short holds; matched A/B pitch/onset/velocity, no pedal |
| Dynamics | Sixteen repeated C notes in a dynamic arch; velocity/timbre versus pitch and tempo |
| Melody/accompaniment | Eight-note RH line over soft block accompaniment; separate-layer A/B, then combined listening |
| Key/pedal duration | Actual CC64 over short C/F key holds; new harmony clears old resonance without changing visual releases |
| Phrasing | Two four-note groups with a small release and softer ending, without adding an accidental extra beat |
| Practising fragments | Three C–E–G–E groups separated by two preparation quarters; entry/exit landmarks and return to a longer passage |
| Major scales (new) | C/G/F ascending scales; 2–2–1–2–2–2–1, degree 3–4/7–8 semitones, F♯ and B♭ |
| Minor scales (new) | A natural versus harmonic, up and down; only G→G♯ changes, F remains natural on descent |
| Seventh chords (new) | Cmaj7/C7/Cm7; root-relative 0–4–7–11, 0–4–7–10, 0–3–7–10; B♭ may display as A♯ |
| Voice leading (new) | Three exact RH lines over C/F/G/C bass; C shared in C→F, no shared tone in F→G, G shared in G→C |
| Compound meter (new) | Twelve eighths with matched A/B timing: 3/4 groups 2+2+2, 6/8 groups 3+3; quarter 90 means dotted-quarter 60 |
| Cadences (new) | Separated G–C, F–C and C–G endings; authentic, plagal and half-cadence direction, with phrase-context qualification |

## Evidence and references

The exact note sets, attack spacing, releases, CC64 events and velocities were
checked directly from the generated MIDI. These examples are original studies;
the references cross-check terminology and are not sources for composition analysis.

- [Simple/compound meter](https://www.musictheory.net/lessons/15) and
  [meter and beat division](https://musictheory.pugetsound.edu/mt21c/meter.html)
  support the distinction between three quarter beats and two dotted-quarter beats.
- [Tuplets](https://musictheory.pugetsound.edu/mt21c/Tuplets.html) supports the
  distinction between subdivision and meter.
- [Seventh chord qualities](https://musictheory.pugetsound.edu/mt21c/SeventhChordsIntroduction.html)
  supports the separate maj7, dominant-seventh and minor-seventh types.
- [Cadences](https://musictheory.pugetsound.edu/mt21c/cadences.html) supports V–I,
  IV–I and an ending on V within phrase context.
- [Yamaha keyboard fingering](https://au.yamaha.com/en/musical-instruments/keyboards/explore/hub/pianists-articles/the-basics-of-piano-keyboard-fingering.html)
  and [even scales](https://hub.yamaha.com/music-educators/instruments/piano/piano-pedagogy-even-scales/)
  inform consistent suggested fingerings and free hand movement. Fingerings here
  are authored suggestions, not a universal hand-size requirement.
